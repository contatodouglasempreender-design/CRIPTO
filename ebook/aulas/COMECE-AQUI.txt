COMECE AQUI — GUIA EM LINGUAGEM SIMPLES

PARA LER
Abra guia-linguagem-simples.pdf. São 22 aulas em 138 páginas.

PARA PREENCHER
1. Abra guia-interativo-simples.html no navegador (Chrome, Edge ou Firefox).
2. Escolha uma aula. Leia a explicação e o exemplo.
3. Veja o exemplo de resposta antes de preencher sua atividade.
4. Escreva suas respostas nos campos.
5. Clique em Minhas respostas para ver o que você escreveu.
6. Use Guardar uma cópia para baixar um arquivo com suas respostas.
7. Para continuar em outro navegador, abra o guia e use Abrir minha cópia.

As respostas ficam no navegador deste aparelho quando ele permite salvar.
Guarde uma cópia antes de trocar de aparelho ou limpar o navegador.
O PDF é para leitura. Os campos para escrever estão no arquivo HTML.
As imagens já estão no arquivo. Depois de baixar, você pode usar sem internet.
As perguntas abertas têm explicações para conferir; não recebem nota automática.
